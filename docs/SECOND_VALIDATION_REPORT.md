## 三、模板匹配验证说明（重要）

人工审核时模板字段**全部选"无推荐"**（20/20），因此**无法用"AI模板=人工模板"计算准确率**。

改用两项结构性指标验证：

| 指标 | 结果 | 说明 |
|---|---|---|
| 映射正确率 | 15/15 = 100% | 所有推荐模板与主类型映射一致（产品介绍→T003） |
| 拦截正确率 | 20/20 = 100% | 功能展示（无模板映射）全部正确返回"无推荐"，未强行套模板 |

**解读：**
- 内容类型修正后，模板推荐从"100% 错误"变为"结构完全正确"
- 人工全选"无推荐"的两种可能：① 审核 UI 默认值（人工未主动选择）；② 人工认为这些素材当前不适合任何模板
- **下一步建议**：审核 UI 增加"模板可用性"确认按钮（适合/不适合/可选 T003），收集真实模板反馈后再定模板准确率

## 五、商业评分偏差（22.4，未达标 ≤15）

### 偏差分布

| 偏差区间 | 条数 | 代表 |
|---|---|---|
| 0-15 | 12 | 多数产品介绍（65-90） |
| 15-30 | 4 | 部分功能展示 |
| 30-60 | 3 | 人工给极低分（0-40）的素材 |
| >60 | 1 | e578a828（V2=76 人工=0） |

### 剩余偏差主因

1. **空镜功能展示**：e578a828 V2=76 vs 人工=0 —— 人工认为纯空镜无价值，V2 因 CLIP 识别到功能标签给高分。**账号 DNA 对"空镜但含功能"的惩罚不足**
2. **人工极低分素材**：a84851ae V2=76 vs 人工=10、d257f90d V2=66 vs 人工=0 —— 人工对"无客户实景"素材系统性压低，V2 未完全拟合
3. **样本不足**：20 条无法校准人工的主观评分偏好（同一类素材人工给 0-90 波动大）

### 结论
商业评分**方向已修正**（系统性高估消除），但 **22.4 > 15 目标未达标**。需更多人工评分样本做阈值校准，属"账号 DNA 训练"阶段任务，不是 P0 规则缺陷。

### 建议（等待用户确认）

**方案 A（推荐）：条件性扩大**
- 内容类型与模板已验证稳定 → 可扩大至 100 条
- 但扩大时**同时收集商业评分样本**（审核 UI 强制填写），扩大后商业偏差自然下降
- 商业评分阈值校准作为 100 条阶段的并行任务

**方案 B（保守）：先补商业校准**
- 用现有 20 条继续调商业评分（账号 DNA 惩罚增强）
- 风险：20 条校准商业评分有过拟合风险

**用户之前的判断框架**：错误集中 → 先修；错误分散 → 扩大。当前内容类型错误已从"集中（19条同因）"变为"分散（4条不同边界）"→ **符合扩大条件**。
