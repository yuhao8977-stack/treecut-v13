# Phase 6 内容价值评估系统设计（PHASE6_CONTENT_VALUE_DESIGN.md）

> 版本: V1 | 日期: 2026-08-25
> 状态: 设计稿 + 初版实现（等待人工审核确认）

---

## 一、目标

让 TreeCut 从"知道素材是什么"升级为"知道素材值不值得用于生产"。
素材价值判断是自动生产前的最后一道核心门槛——没有价值判断，自动生产只是自动制造垃圾。

## 二、架构位置


## 三、评分模型（100 分，用户指定权重）

| 维度 | 满分 | 判断依据 | 来源 |
|---|---|---|---|
| **用户价值** | 25 | 是否解决装修问题（动线/小户型/避坑/方案/尺寸） | ASR/OCR 关键词 + 元素 |
| **产品卖点** | 25 | 是否有明确卖点（伸缩/收纳/轨道插座/尺寸/材质） | ASR/OCR 关键词 + 元素 |
| **信任价值** | 20 | 是否建立信任（客户家/案例/工厂实力/安装/质保） | ASR/OCR + 场景语义 |
| **传播价值** | 20 | 是否有爆款可能（冲突/数字/反常识/对比/钩子） | ASR/OCR 钩子词 |
| **转化价值** | 10 | 是否易产生咨询（CTA/定制/报价/私信/扣1） | ASR/OCR CTA 词 |

## 四、评分逻辑（V2 人工校准版）

### 4.1 基准分（内容类型锚定，来自 100 条人工均值）

| 内容类型 | 基准 | 依据 |
|---|---|---|
| 客户案例 | 75 | 人工均值 |
| 产品介绍 | 63 | 人工均值 |
| 功能展示 | 50 | 人工均值 |
| 产品展示 | 45 | 人工均值 |
| 装修方案 | 60 | 估算 |
| 知识分享 | 55 | 估算 |
| 品牌展示 | 40 | 估算 |
| 其他 | 10 | 人工均值 |

基准按权重比例拆分到五维，再微调。

### 4.2 低价值惩罚（关键校准）

| 场景 | 惩罚 | 依据（人工） |
|---|---|---|
| 空镜 + 功能/产品展示/案例类型 | 用户/传播 ×0.75 | 人工对产品空镜给 65-75 |
| 空镜 + 产品介绍类型 | 用户/传播 ×0.45 | 无内容的产品介绍空镜 |
| 讲解但无真实信息（空洞话术） | 用户 ×0.4 / 传播 ×0.5 + **总分封顶 40** | 人工对空洞素材打 10-40 |
| 承诺句式（"没问题/保证/十年"） | 同上 | 人工 10 分素材特征 |

### 4.3 防误判措施

- **繁简归一化**：繁体 ASR（颜色搭配/伸缩/薄抽）转简体再匹配
- **品牌水印过滤**：OCR"坤宝岛台/品控/成就非凡"等不算真实信息
- **产品信号兜底**：ASR 含"岛台/导台/台面/柜"等 → 不算空洞

## 五、素材池分类（ABCD）

| 池 | 评分 | 用途 |
|---|---|---|
| **A 直接可生产** | ≥70 且有讲解/案例 | 直接进入生产池 |
| **B 需要组合** | 55-69 | 与其他素材组合成片 |
| **C 备用素材** | 40-54 | 保留备用 |
| **D 低价值** | <40 | 不推荐使用 |

## 六、数据存储

新表 `content_value`：
```sql
CREATE TABLE content_value (
    asset_id   TEXT PRIMARY KEY,
    user_value   REAL,   -- 用户价值 0-25
    product_merit REAL,  -- 产品卖点 0-25
    trust_value  REAL,   -- 信任价值 0-20
    comm_value   REAL,   -- 传播价值 0-20
    deal_value   REAL,   -- 转化价值 0-10
    total_score  REAL,   -- 总分 0-100
    pool_class   TEXT,   -- A/B/C/D
    pool_reason  TEXT,   -- 分类原因
    computed_at  REAL
);
```

## 七、验证结果（100 条测试集，20 条人工评分对比）

| 指标 | 值 |
|---|---|
| 价值评分 vs 人工评分相关系数 | **0.631** |
| 高/低分级一致率（≥60 vs <60） | **90%（18/20）** |
| 人工 90 分素材 → A 类 | ✅ |
| 人工 10 分空洞素材 → C 类 | ✅ |

## 八、待确认事项（等待人工审核）

1. **空镜细分**：静态空镜（人工 20）vs 功能演示空镜（人工 65）当前区分不足（样本仅 1 条）
2. **产品价值空镜加分**：空镜产品素材的产品价值是否应从 CLIP 视觉标签补充（当前仅文本）
3. **ABCD 阈值**：70/55/40 是否合理，需全量素材分布确认
4. **商业评分联动**：Phase6 价值评分与模板系统商业评分的权重关系
