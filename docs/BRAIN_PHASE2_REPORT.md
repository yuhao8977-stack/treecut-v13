## 1. 实施内容

### 1.1 账号适配度引擎（`cognitive/account.py`）

基于 `account_dna` 高/中/低价值特征，计算素材对账号（坤宝岛台）的适配度：

| 评分项 | 分值 |
|---|---|
| 内容类型基础分 | 客户案例 45 / 产品介绍 40 / 装修方案 35 / 避坑 35 / 工厂实力 20 |
| 高价值特征命中 | +12/个 |
| 中价值特征命中 | +6/个 |
| 低价值特征命中 | -15/个 |

**语义匹配**：账号特征是运营术语（"尺寸展示/收纳展示"），素材文本是内容词（"伸缩/抽屉"）——用核心词剥离 + 双向包含匹配解决。

### 1.2 模板匹配引擎（`cognitive/template.py`）

| 内容类型 | 推荐模板 | 结构 |
|---|---|---|
| 客户案例 | T001 | 结果展示→客户背景→功能卖点→CTA |
| 产品介绍 | T003 | 产品亮相→卖点拆解→细节特写→CTA |
| 工厂实力 | T002 | 工厂开场→生产→产品展示→品质→引导 |
| 避坑知识 | T004 | 痛点→避坑→方案→互动 |

**槽位建议**：每个模板槽位输出填充建议（基于素材关键帧/场景段/ASR 解说可用性）。

### 1.3 商业价值评分（0-100）

```
内容类型加分（客户案例+25/产品+20/避坑+20/方案+18/工厂+15）
+ 镜头价值×0.3（多段/多关键帧/有解说加分）
+ 解说丰富 +8 / 画面文字 +5
```

### 1.4 全链路认知输出（`brain.py` 整合）

单素材完整输出（设计文档 §4.5 格式）：
```
ai_understanding → 感知 → 行业(产品/材料/功能/场景)
→ 内容类型 → 账号适配 → 模板推荐 → 商业价值+原因
```

```

```

**与设计文档 §4.5 目标格式对比**：字段齐全（素材/AI理解/内容类型/适合账号/推荐模板/商业价值/原因），达标 ✅

## 4. 局限与后续

| 局限 | 说明 | 对策 |
|---|---|---|
| 无 ≥70 高适配素材 | 当前账号特征偏严格，或素材本身以中等价值为主 | 人工审核后调整 DNA 权重；积累更多账号配置 |
| 纯画面素材（无 ASR） | 行业识别缺失导致适配/商业分偏低 | Phase 2b 接入视觉模型（Qwen-VL） |
| 商业价值为规则估分 | 非人工审核值 | 与 P2.7 asset_quality 人工评分对账校准 |
