# TreeCut 第一轮规则优化建议（learning_rules_update_plan.md）

> 生成时间: 2026-08-24
> 数据源: 20 条人工审核（accuracy_review）
> 原则: **本文件仅记录优化建议，未修改任何代码；待人工确认后执行**

## 规则001 [P0]

- **问题**：AI 把所有工厂内产品讲解视频识别为"客户案例"
- **当前AI判断**：客户案例（19/20 条）
- **人工判断**：产品介绍（11）/ 功能展示（7）/ 其他（1）
- **优化规则**：
  ```
  如果：场景 ∈ {工厂, 展厅}
  AND 文本含产品讲解话术（尺寸/材质/功能/这款/设计/台面）
  AND 无完工证据（无: 完工/交付/实景/客户家/已经安装）
  则：优先判定 产品介绍
  ```
- **影响模块**：`cognitive/industry.py` → `CONTENT_TYPE_RULES` / `_classify_content`

## 规则002 [P0]

- **问题**：客户称呼词（女士/小姐/先生/委托）被当作客户案例强证据
- **当前AI判断**：命中"李女士/李小姐/委托"→ 客户案例
- **人工判断**：客户委托定制话术 ≠ 客户案例内容；主体仍是产品讲解
- **优化规则**：
  ```
  客户案例需强证据：完工/交付/实景/入户/客户家/安装完成 至少 1 个
  客户称呼词（女士/小姐/先生/委托/定制）权重下调，不作为判定依据
  若客户称呼词 + 产品讲解词 同时命中 → 判 产品介绍
  ```
- **影响模块**：`cognitive/industry.py` → `CONTENT_TYPE_RULES["客户案例"].keywords`

## 规则003 [P0]

- **问题**：AI 系统性高估工厂/展厅产品视频的商业价值
- **当前AI判断**：66-94 分
- **人工判断**：0-40 分（无客户实景、无传播性、非账号调性）
- **优化规则**：
  ```
  如果：无客户实景证据（无: 完工/交付/实景/客户家/安装）
  AND 场景 ∈ {工厂, 展厅}
  则：成交价值 ≤ 20 分，内容传播 ≤ 20 分，商业总分上限 50
  （账号 DNA：坤宝岛台 — 纯工厂流水线视频对账号无价值）
  ```
- **影响模块**：`cognitive/template.py` → `_business_score` / `cognitive/account.py`

## 规则004 [P0]

- **问题**：模板推荐与 content_type 硬映射，content_type 全错导致模板全错
- **当前AI判断**：20/20 全部推荐 T001（客户案例模板）
- **人工判断**：20/20 全部"无推荐"
- **优化规则**：
  ```
  模板推荐前置条件：content_type 置信度 ≥ 0.6 才启用映射
  若 content_type 为 产品介绍/功能展示 且无匹配模板 → 返回"无推荐" + 原因
  模板库需补充 产品介绍模板/功能展示模板（未来自动生产前置）
  ```
- **影响模块**：`cognitive/template.py` → `recommend` / `CONTENT_TEMPLATE_MAP`

## 规则005 [P1]

- **问题**：真实高频场景"展厅产品展示"未被识别
- **当前AI判断**：工厂/厨房空间/安装现场
- **人工判断**：展厅产品展示（多处备注"工厂，产品展示"实为展厅）
- **优化规则**：
  ```
  scene 词库补充：展厅产品展示（keywords: 展厅/样品/陈列/展示台/样板间）
  场景识别与内容意图联动：展厅+讲解 → 产品介绍
  ```
- **影响模块**：`knowledge/TreeCut_AI_Brain/scene/*.json`

## 规则006 [P1]

- **问题**：产品识别粒度粗（仅 岛台/实木岛台/奢石岛台），11/20 条产品为空
- **当前AI判断**：岛台 / 实木岛台 / 奢石岛台（或空）
- **人工判断**：伸缩岛台 / 岩板岛台 / 中古风岛台 / 石木钢结构岛台 / 半岛台
- **优化规则**：
  ```
  product 词库补充：伸缩岛台、岩板岛台、中古风岛台、石木钢岛台、半岛台、功能岛台
  产品词 = 材质词 + 岛台 组合识别（如 岩板+岛台 → 岩板岛台）
  ```
- **影响模块**：`knowledge/TreeCut_AI_Brain/product/*.json`

## 规则007 [P1]

- **问题**：花色/材质词不足（雅光白/骑士黑/阿米利亚未命中）
- **当前AI判断**：木纹/潘多拉/肤感/黑胡桃
- **人工判断**：含具体花色（备注中出现 骑士黑雅光/阿米利亚浅中）

  material 词库补充：雅光白、骑士黑、阿米利亚、伊诺雅光白、黑白根

## 规则008 [P2]

- **问题**：置信度全部锁定 0.52，无区分度
- **当前AI判断**：20/20 条 confidence = 0.52
- **人工判断**：——（人工按内容判，不看置信度）
- **优化规则**：
  ```
  置信度公式区分度：min(0.95, 0.4 + 0.12×命中数) 改为
  按命中词权重求和 + 证据类型加权（强证据+0.2 / 弱证据+0.05）
  消除工厂权重 0.9 反向压低问题
  ```
- **影响模块**：`cognitive/industry.py` → `_classify_content`

## 规则009 [P2]

- **问题**：约 20% 素材 ASR 为繁体，简体关键词库命中率低
- **当前AI判断**：繁体文本命中率低 → 分类置信度低
- **人工判断**：繁体内容可正常判断
- **优化规则**：
  ```
  ASR 文本预处理：繁体→简体 归一化（opencc 或内置映射）
  再执行关键词匹配
  ```
- **影响模块**：`cognitive/brain.py` → `_layer01` 文本归一化
