# TreeCut 内容类型系统 V2 设计文档（CONTENT_TYPE_V2_DESIGN.md）

> 版本: V2 | 日期: 2026-08-24
> 来源: 第一轮 20 条人工审核校准（内容类型一致率 5% → 85%）

---

## 一、为什么升级（第一轮人工反馈结论）

原 V1 单标签分类的核心缺陷（20 条审核实证）：

| 缺陷 | 实证 |
|---|---|
| 单标签无法表达复合内容 | "浙江婉小姐委托定制潘多拉木纹岛台" 实际 = 产品介绍主体 + 客户案例背景 |
| 客户称呼词误当客户案例证据 | ASR 出现"李女士/委托/定制"即判客户案例 → 19/20 条误判 |
| 无内容意图判断 | 只能回答"视频里有什么"，不能回答"为什么拍" |
| 置信度无区分度 | 20/20 条 confidence 全部锁定 0.52 |
| 空镜素材文本缺失 | 纯画面素材（ASR/OCR 空）无法分类 |

## 二、双层结构定义

### 第一层 content_type_main（内容主体）— 回答"主要卖什么/为什么拍"

| 主类型 | 定义 | 人工均值商业分 |
|---|---|---|
| 产品介绍 | 讲解产品卖点（尺寸/材质/功能） | ≈63 |
| 客户案例 | 完工交付、真实客户空间 | ≈75 |
| 功能展示 | 演示产品功能（收纳/伸缩/隐藏电器） | ≈50 |
| 装修方案 | 户型/布局/动线解决方案 | - |
| 知识分享 | 避坑/经验/干货 | - |
| 品牌展示 | 工厂实力/品牌 | - |
| 其他 | 无法归入以上 | ≈0 |

### 第二层 content_elements（内容元素）— 回答"里面有什么"

`客户案例背景 / 尺寸展示 / 材质展示 / 功能展示 / 空间展示 / 安装过程 / 前后对比 / 客户反馈 / 工厂工艺 / 真人讲解`

## 三、证据机制（P0-2 核心）

### 3.1 客户案例强证据门槛（≥2 个）

```
客户案例必须满足 ≥2 个强证据：
  完工 / 交付 / 实景 / 入户 / 家里 / 客户家 / 安装完成 /
  已经装好 / 装好了 / 效果 / 落地 / 对比 / 客户反馈 /
  满意 / 入住 / 新家
```

### 3.2 反向排除（客户称呼词不构成证据）

```
女士 / 小姐 / 先生 / 委托 / 定制 / 客户
→ 仅加入"客户案例背景"元素，弱证据权重 0.1，不构成客户案例证据
```

### 3.3 内容意图优先级（P0-1 核心）

```
判定顺序：
1. 客户案例强证据 ≥2 → 客户案例
2. 产品讲解词（尺寸/材质/功能/岛台…）命中
   + 工厂/展厅场景 → 产品介绍（核心修正）
3. 功能词命中（收纳/抽屉/伸缩/隐藏/插座…）→ 功能展示
4. 路径含"产品类/空镜"（空镜素材）→ 产品介绍
5. 装修/知识/品牌词 → 对应类型
6. 内容元素线索兜底 → 其他
```

## 四、多模态信号接入

| 信号源 | 用途 | 覆盖 |
|---|---|---|
| ASR 文本 | 主类型/元素证据 | 有讲解素材 |
| OCR 文本 | 补充证据 | 画面文字 |
| 素材路径 | "产品类/空镜/工厂类" 目录信号 | 空镜素材 |
| CLIP 视觉语义 | 场景/产品/材质/功能标签（视觉:xxx） | 空镜素材，功能标签优先 |

**关键实现**：`content_classification.reasons.vision` 保存 CLIP 标签（industry._persist 不覆盖），`_collect_text`/`_get_text` 读取时按 function → material → product → scene 优先级拼接。

## 五、置信度公式 V2（P0-4）

```
客户案例:  conf = min(0.95, 0.5 + 强证据数 × 0.15)
其他类型:  conf = min(0.95, 0.45 + 0.45 × 主分/(主分+次高分))
下限 0.2，上限 0.95
```

实测分布：0.675 ~ 0.881（消除了 0.52 锁定，有区分度）。

## 六、持久化与兼容

- `content_classification` 新增 `content_elements` 列（幂等 ALTER TABLE 迁移）
- `content_type` 存主类型（兼容旧字段），`content_elements` 存元素 JSON
- `reasons` 增加 `content_elements` / `evidence` / `vision` 字段
- model_version 升级为 `brain-industry-v2`

## 七、优化前后对比（20 条测试集）

| 指标 | V1（旧） | V2 | 提升 |
|---|---|---|---|
| 内容类型一致率 | 5% (1/20) | **80% (16/20)** | +75pt |
| 客户案例误判数 | 19 | **0** | 消除 |
| 置信度区分度 | 全部 0.52 | 0.66-0.84 | ✅ |
