# 升级任务 04：真实高清最终成片

## 要解决的问题

旧生产链无论是否导出最终 MP4，都先使用 `preview` 规格渲染 540×960。后续字幕烧录只是重新编码同一尺寸，因此所谓最终成片仍是预览清晰度。代码虽然定义了 1080×1920 `final` 规格，却没有正式调用。

## 完成内容

- MP4 请求必须选择 `final` 渲染规格。
- 最终画面底片改为 1080×1920。
- 配音、音乐和字幕流程继承高清底片尺寸。
- 仅导出剪映草稿时仍使用轻量 preview，避免无意义的高清中间渲染。
- 高清底片文件改名为 `01_高清画面底片.mp4`，不再冒充预览。
- 生产报告新增 `render_profile` 证据。
- 最终质量检查从“至少 540×960”收紧为“精确 1080×1920”。
- 540×960 文件现在必定不能通过最终成片分辨率检查。

## 验收结果

- 新增 4 项规格选择和分辨率回归测试。
- 全量自动测试由 72 项增加到 76 项，76/76 通过。
- 真实 FFmpeg 底片验证：2 秒、H.264、1080×1920、2,062,677 字节。
- 真实完整生产验证：卖点匹配 → 高清底片 → 离线配音 → 背景音乐 → 中文字幕烧录 → 质量回读。
- 完整成片：5.0 秒、1080×1920、H.264、包含音轨。
- 生产报告 `render_profile=final`。
- 质量中心 11 项检查全部通过，分辨率实际值 1080×1920，期望值“精确 1080×1920”。
- 全部验证数据位于 G 盘隔离目录，C 盘 Ultralytics 文件数为 0。
