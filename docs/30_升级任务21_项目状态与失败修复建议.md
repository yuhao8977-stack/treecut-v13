# 升级任务 21：项目状态、完整错误证据与修复建议

以前质量失败只在任务库保存一行错误，输出项目目录本身没有成功/失败标记；用户可能把半成品误认为成片，也无法看完整堆栈。

现在每个制作请求一开始就建立独立项目并原子写入 `STATUS.json`：

- `running`：正在制作。
- `success`：所有生成和质量检查结束。
- `failed`：任意匹配、模型、渲染、配音、草稿或质量步骤失败。

失败状态包含错误类型、完整 traceback 和小白修复建议。对分辨率、音轨、字幕、草稿源文件、时间线越界等质量代码提供专门建议；未知错误指向本项目状态文件和 G 盘日志。桌面与 API 同时使用 logger.exception 保存完整堆栈。

新增测试证明失败不会留在 running，成功也不会被误标失败。当前 125 项测试通过。
