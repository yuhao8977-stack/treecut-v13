# 升级任务 16：便携运行时去重与禁止串用旧环境

## 处理的问题

便携 Python 同时在 `runtime\Lib` 与 `runtime\Lib\site-packages` 安装了大量相同版本第三方包。Python 会按路径先后随机表现成“升级了一套，实际读取另一套”，也是 Whisper OpenMP 冲突和跨电脑幽灵问题的重要来源。

桌面启动器在自身 Python 缺失时还会搜索相邻旧项目，这会让损坏安装表面上仍能启动，但实际运行未知旧代码。

## 已执行

- 识别 67 个名称和版本完全相同的重复 distribution。
- 将 `runtime\Lib` 中有 RECORD 清单、且标准 `site-packages` 有相同名称版本的 7,163 个文件移入 G 盘隔离区，没有删除。
- 统一验证 Torch、Transformers、FastAPI、CTranslate2、NumPy 均从 `site-packages` 加载。
- 桌面启动只允许自身 `runtime\pythonw.exe`；缺失时明确报损坏，禁止借用邻居环境。
- 所有直接 Python 入口强制覆盖 TEMP、HF、Torch、YOLO、pip、Matplotlib、pycache 等缓存到安装盘。
- Windows 上若数据根或模型根被配置到 C 盘，启动立即拒绝。
