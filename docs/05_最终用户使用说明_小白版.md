# TreeCut v13 最终用户使用说明（小白版）

## 你现在拿到的是什么

TreeCut v13 是一个离线优先的 Windows 视频自动剪辑软件原型。它可以扫描大量本地视频，分析画面、人物和语音，根据你填写的产品卖点挑选镜头，再生成配音、字幕、背景音乐、可播放 MP4 和剪映草稿。

干净便携版位置：`G:\TreeCut_v13_release_candidate`

它自带 Python、FFmpeg 和核心模型，不要求把程序、模型、缓存或项目放到 C 盘。换盘符或复制到另一台 Windows 电脑后，启动器会按软件所在位置重新定位。

## 第一次使用

1. 双击 `检查树剪安装.cmd`。看到 24 项全部通过后再使用。
2. 双击 `启动树剪v13.cmd`。
3. 在素材库区域添加视频所在文件夹，然后点击扫描/分析。
4. 输入产品卖点和配音文案，选择时长和输出方式。
5. 可选择“最终视频”“剪映草稿”或两者都要，然后提交制作。
6. 在任务记录中查看排队、运行、成功或失败；被断电、拔盘中断的任务可以重试。

## 软件现在真正会做的事

- 自动登记素材盘；盘符变化后可根据磁盘身份重新关联。
- Florence 分析代表画面，YOLO 检测人物和常见物体。
- SenseVoice 离线识别中文口播，并生成带时间段的文字。
- 根据画面描述、语音、分类、关键词和用户反馈解释选材原因。
- 离线生成中文配音、字幕和背景音乐混音。
- 生成竖屏 MP4，并检查时长、分辨率、音轨、黑屏、冻结、静音和字幕像素证据。
- 生成包含画面、配音、音乐、字幕四类轨道的剪映草稿。
- 保存“保留、替换、永久禁用”反馈，影响下一次选材。

## 使用时要知道的限制

- 当前笔记本没有 CUDA 独立显卡，所以使用 Florence CPU 模式；分析一条视频可能约一至数分钟，这是正常的。
- Qwen3-VL 已接线但只会在至少 10GB 可用显存的兼容 NVIDIA 电脑上启用；目标台式机仍需要做一次真实 GPU 验收。
- 当前口播时间轴是分段级，不是逐字级，但已经足够用于镜头定位和字幕生成。
- 软件能检查技术质量，不等于能像专业导演一样保证审美。用户的保留/替换反馈是持续改善选材的依据。
- 剪映版本格式可能变化；如果未来剪映升级导致草稿不兼容，需要更新适配器。

## 数据放在哪里

软件产生的数据全部位于软件目录下的 `runtime_data`：素材数据库在 `database`，缓存位于 `cache`，输出位于 `output`，日志位于 `logs`。不要在任务运行中拔掉安装软件的 SSD。

## 搬到其他电脑

完整复制整个 `TreeCut_v13_release_candidate` 文件夹，不要只复制启动文件。复制后先运行安装检查。普通 CPU 电脑会自动使用轻量方案；满足条件的 NVIDIA 电脑可使用 Qwen3-VL。素材可以在别的硬盘或共享盘，软件会登记实际位置。
