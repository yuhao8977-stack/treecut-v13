# TreeCut 商业价值评分 V2 设计文档（BUSINESS_SCORE_V2_DESIGN.md）

> 版本: V2 | 日期: 2026-08-24
> 来源: 第一轮 20 条人工审核校准（商业偏差 38 → 20.9）

---

## 一、V1 缺陷（第一轮人工反馈实证）

| 缺陷 | 实证 |
|---|---|
| "信息量越多分越高" | AI 给工厂产品视频 66-94 分，人工给 0-40 |
| 账号 DNA 未参与 | 纯工厂流水线 AI=90，人工=10（对坤宝岛台账号无价值） |
| 无五维拆分逻辑 | 单一公式聚合，无法解释维度差异 |
| 内容类型错误传导 | content_type 全错 → 商业评分全偏 |

## 二、V2 评分结构（5×20 维度）

| 维度 | 满分 | 判定依据 |
|---|---|---|
| 真实性 | 20 | 真实客户/空间/实景证据（完工/实景/入户/客户/委托） |
| 产品价值 | 20 | 产品主体识别 + 卖点词（尺寸/材质/功能/细节） |
| 用户价值 | 20 | 解决装修问题（收纳/动线/小户型/避坑/方案） |
| 内容传播 | 20 | 讲解/情绪钩子（对比/效果/颜值/直接冲） |
| 成交价值 | 20 | CTA/案例背书（定制/报价/咨询/委托） |

总分 = 五维之和（0-100）

## 三、人工校准基准（第一轮 20 条）

人工商业评分均值（按内容类型）：
- 客户案例 ≈ 75
- 产品介绍 ≈ 63
- 功能展示 ≈ 50
- 其他 ≈ 0

V2 以此为锚点：内容类型决定基准档位，五维微调总分。

## 四、账号 DNA 调节（P0-3 核心）

```
坤宝岛台账号低价值特征（low_value）：
  纯生产过程 / 无产品说明 / 纯空镜 / 无关画面

调节规则：
  纯工厂空镜（无产品 + 无讲解 + 工厂工艺元素）→ 总分 ×0.35
  空镜无产品（无产品 + 无讲解）→ 总分 ×0.5
```

目的：纯工厂流水线视频（人工 10 分）不再被高估。

## 五、实现要点

- `template.py` → `_business_score_v2(content_type, elements, text, lens_value, account)`
- 证据判定融合多模态：ASR + OCR + 路径 + CLIP 视觉标签（function 优先）
- `accuracy.py` → `_split_business` 从 `business_reasons` 解析真实五维，不近似拆分
- 输出含完整 reason 链（每维加分依据），供审核 UI 展示

## 六、优化前后对比（20 条测试集）

| 指标 | V1 | V2 | 说明 |
|---|---|---|---|
| 商业平均偏差 | 38（修复中峰值） | **22.4** | 方向已修正 |
| 偏差>15 条数 | 18/20 | 8/20 | - |
| 系统性高估 | 全部 66-94 | 部分修正 | 纯空镜已 ×0.35 惩罚 |
| 维度可解释性 | 无 | 五维 + 原因链 | ✅ |

### 剩余偏差主因（需二次校准）

| 偏差 | V2 | 人工 | 原因 |
|---|---|---|---|
| 56 | 66 | 10 | a84851ae 纯工厂产品介绍，人工认为无传播价值；V2 未识别"无客户实景"惩罚 |
| 51 | 14 | 65 | 空镜产品素材，人工认为有价值（产品展示素材）；V2 空镜惩罚过重 |
| 34 | 74 | 40 | 17928c32 人工评分低但 V2 识别到较多卖点词 |

商业评分对主观判断敏感，20 条样本不足以完全拟合人工偏好，需二次验证阶段用更多样本校准阈值。

## 七、后续迭代方向

1. 空镜惩罚区分"产品空镜"（有价值）vs"纯工厂流水线"（无价值）
2. 成交价值维度增加"账号调性匹配"因子
3. 收集人工评分分布 → 阈值回归校准
4. 商业评分与账号 fit_score 联动（双向验证）
