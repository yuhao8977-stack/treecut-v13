## 二、边界可用性量化（基于可计算证据）

> 说明：本 Phase 无视觉时序模型，边界审计用**代理指标**（关键帧覆盖度/ASR 覆盖度/技术质量）
> 量化问题规模。动作截断/语义混杂需 Phase 3 视觉时序后精确判定。

| 指标 | 5s 组（166） | 检测器组（134） |
|---|---|---|
| 平均关键帧数/segment | 7.3 | 6.74 |
| ASR 覆盖（有 ASR 的 %） | 82.5% | 68.7% |
| 技术质量可计算率 | 100% | 99% |

### 边界可用率（代理估计）

- **5s 组**：由于 5s 固定切分与真实镜头边界无对齐关系，**动作截断风险高**。
  例：ASR 段边界 780-6900ms 横跨 0-5000/5000-9926 两个 segment → 语义被切分。
- **检测器组**：ContentDetector 检测的真实场景边界，截断率预期低于 5s 组，
  但场景级边界 ≠ 动作级边界（动作可能在场景内部被 5s 兜底切分）。

### 关键证据（真实样例）

```
segment 0069edd3aa84（5s 组）范围 5000-9926ms
ASR hit 1: 780-6900ms "这个圆湖下雪边很值得有小朋友的家庭学习起来"
ASR hit 2: 6900-8700ms "很丝滑 防客碰啊"
→ 语义（讲解产品优点）横跨 segment 边界，单 segment 语义不完整
```
