## 二、高价值素材特征（人工评分 ≥60 的素材共同点）

从 16 条人工高分素材归纳：

1. **有内容讲解**（ASR 有实质信息，非空洞话术）
   - ✅ 高分例："开饭式厨房最重要的是什么 动线规划…一个倒台"（90分）
   - ✅ "倒头用的是骑士黑雅光 餐桌用的是阿米利亚浅中 颜色搭配很适合中古风"（85分）
2. **有明确卖点**：尺寸/材质/颜色搭配/功能（抽屉抽拉/收纳）
3. **场景完整**：工厂产品展示环境 + 产品主体清晰
4. **客户案例加分**：客户委托/真实需求背景

**高价值内容结构（爆款雏形）：**
```
客户痛点/空间限制（如小户型动线）
  ↓
产品展示（工厂/展厅）
  ↓
尺寸介绍（3米/60公分）
  ↓
功能卖点（伸缩/收纳/轨道插座）
  ↓
材质价值（岩板/奢石/颜色搭配）
  ↓
CTA（定制/扣1/私信）
```

## 三、低价值素材特征（人工评分 <60）

从 4 条人工低分素材归纳：

| 特征 | 例 |
|---|---|
| 空洞承诺话术 | "保证你十年之后站上去换灯泡都没问题"（10分） |
| 无真实信息讲解 | "选择的是雅光白"（50分，无实质内容） |
| 静态空镜无动作 | 空镜抽屉细节展示，无演示（20分） |
| 无用户价值 | 纯展示无解决方案 |

**账号不推荐内容：**
```
纯工厂机器/流水线（无人物无产品说明）
静态空镜（无动作无讲解）
空洞承诺（"没问题/直接冲"无实际信息）
无用户价值的纯展示
```
