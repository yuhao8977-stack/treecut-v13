# TreeCut 声音参考录音指南（真人克隆/校准用）

> 目的：为 VoiceProvider 提供合规、高质量参考样本。**无授权样本前系统保持 VOICE_INPUT_REQUIRED / SAPI=FALLBACK_TTS，不宣称 Production 就绪。**

## 最低要求（30–60 秒，先录这个即可跑通）
- 单人、无 BGM、环境安静、低混响、普通话自然语速
- 内容建议：
  1. 自我介绍句 ×2
  2. 数字（30 公分、60 公分、1.8 米、1080×1920）
  3. 产品词：岛台、岩板、轨道插座、上层薄抽、伸缩桌面、柜门、收纳
  4. 一句长句 + 一句短句

## 推荐（5–10 分钟，正式克隆前录）
- 同一人一次性录完；保持口吻一致（销售/讲解/生活化各一段可选）
- 录制格式：WAV 48kHz 单声道（或手机原文件+说明）
- 每段之间停顿 1–2 秒

## 录制清单（对着念）
```
大家好，我是坤宝工厂的讲解员，今天带你看岛台的几个设计细节。
第一，上层薄抽，用来收纳小物件，不用弯腰，打开就能拿到。
第二，轨道插座，吃火锅、煮茶都很方便，插拔也很顺手。
第三，伸缩桌面，客人来的时候一拉就变宽，平时收起来不占地方。
这块岩板台面是 60 公分进深，总长可以做到 1.8 米到 2.4 米。
抽屉用的是三节托底导轨，抽拉非常顺滑。
有需要的话可以联系我们，工厂在佛山，支持定制。
```
（可按你的真实口播替换，保持上面覆盖的词汇类型）
