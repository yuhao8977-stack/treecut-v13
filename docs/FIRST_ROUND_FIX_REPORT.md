## 二、执行的 P0 任务（用户批准清单）

### 任务1：重构内容类型系统（P0-1）✅
- 单标签 → **双层结构**：`content_type_main`（主体）+ `content_elements`（元素）
- 主类型：产品介绍/客户案例/功能展示/装修方案/知识分享/品牌展示/其他
- 元素：客户案例背景/尺寸展示/材质展示/功能展示/空间展示/安装过程/前后对比/客户反馈/工厂工艺/真人讲解
- 内容意图判断：**有实质讲解（ASR≥12字）+ 产品词 → 产品介绍优先**

### 任务2：重构客户案例判断规则（P0-2）✅
- **证据机制**：客户案例需 ≥2 个强证据（完工/实景/入户/前后对比/客户反馈/入住…）
- **反向排除**：女士/小姐/先生/委托/定制 → 仅作为"客户案例背景"元素，权重 0.1，不构成证据
- 实证：19 条误判全部消除

### 任务3：重构商业评分（P0-3）✅（方向修正）
- 5×20 维度：真实性/产品价值/用户价值/内容传播/成交价值
- **账号 DNA 调节**：纯工厂空镜 → 总分 ×0.35；空镜无产品 → ×0.5
- 人工校准基准：客户案例≈75 / 产品介绍≈63 / 功能展示≈50 / 其他≈0

### 任务4：置信度重构（P0-4）✅
- 公式：`min(0.95, 0.45 + 0.45 × 主分/(主分+次高分))`（客户案例用证据数）
- 消除 0.52 锁定，实测 0.66-0.84

### 任务5：重新计算 20 条 ✅
- 未修改任何人工结果（accuracy_review 20 条原样保留）
- 重新运行 AI 判断（accuracy_test.ai_analysis 更新，reviewed 状态保留）
