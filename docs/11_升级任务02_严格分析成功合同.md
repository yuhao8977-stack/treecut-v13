# 升级任务 02：严格分析成功合同

## 要解决的问题

旧逻辑会分别捕获视觉、语音和 YOLO 错误，但最后仍可能把任务保存为 success。这样“抽到了帧”可能掩盖“模型根本没完成”。

## 新成功合同

必需项：

- 媒体参数必须由 FFprobe 真实读取。
- 至少抽取一张有效视频帧。
- 画面模型必须实际运行、没有错误并返回非空描述。
- 视频有音轨时，语音模型必须实际运行并完成。
- 语音模型完成后判断“没有有效人声”属于合法结果；模型没运行或报错不合法。

可选项：

- YOLO 是增强证据。失败不会摧毁已经完成的核心视觉和语音分析，但结果必须标为 degraded，并保存具体警告。

## 数据证据

每条新结果新增：

- `vision_attempted` / `vision_completed`
- `speech_expected` / `speech_attempted` / `speech_completed`
- `object_detection_expected` / `object_detection_attempted` / `object_detection_completed`
- `completion.status`
- `completion.required_failures`
- `completion.optional_warnings`

分析管线版本升级为 `13.2.0`，保证旧标准结果不会被继续复用。

## 验收结果

- 新增 5 项成功合同测试。
- 全量自动测试由 63 项增加到 68 项，68/68 通过。
- 使用真实 MP4 运行完整正式工作器：1/1 成功，耗时约 168 秒。
- Florence 返回 1 条有效画面描述，无错误。
- SenseVoice 完成真实语音分析并识别到人声，无错误。
- YOLO 检测到 2 个人物目标，无错误。
- 数据库保存 `analysis_version=13.2.0`、`schema_version=2`。
- `completion.status=complete`，所有必需证据为 true。
- 验证缓存、数据库和 Ultralytics 配置全部位于 G 盘；C 盘 Ultralytics 文件数为 0。
