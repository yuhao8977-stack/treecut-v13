# TreeCut v13 模型最终去留（小白版）

## 正式核心模型

### Florence-2-base：保留

- 用途：理解视频代表画面并生成文字描述；
- 当前笔记本：真实运行通过；
- 普通 CPU 电脑：只分析中间代表帧以降低内存和耗时；
- 有足够显存的电脑：可以分析三帧，提高镜头覆盖率。

### SenseVoiceSmall：保留

- 用途：完全离线识别人声和行业文案；
- 当前笔记本：真实运行通过；
- 时间轴精度：固定音频分段，不冒充词级时间轴；
- Whisper 不可用时，它是正式备用方案，不是临时假结果。

### YOLOv8n：保留并正式接线

- 用途：识别人、餐桌、烤箱等通用物体；
- 当前笔记本：真实识别出 oven、person、bowl、cake、dining table；
- 检测结果保存类别、置信度和画面坐标；
- 旧状态是“有文件、有策略、正式入口不调用”，现已解决。

### Sherpa-ONNX VITS：保留

- 用途：完全离线中文/英文配音；
- 当前笔记本：真实生成 44.1 kHz WAV，并已进入成片生产链路；
- 不依赖网络服务。

## 条件启用模型

### Qwen3-VL 4B FP8：保留为高显存增强

- 权重约 5.62 GiB，配置、两份权重分片、处理器和 tokenizer 均完整；
- 已补正式推理适配器和失败回退 Florence；
- v13 只有检测到 NVIDIA CUDA 且显存至少 10 GB 才会尝试启用；
- 当前无显卡笔记本不能完成真实 Qwen 推理，必须回到目标台式机再做 GPU 验收；
- 8 GB 显存不再强行启用，避免加载后爆显存。

### Faster-Whisper：暂不启用

- 用途：更精细的词级语音时间轴；
- 运行代码和适配器已存在；
- `Whisper-small` 当前为 0 文件，没有 `model.bin` 和 `config.json`，因此明确标记不可用；
- 当前 SenseVoice 已能完成离线语音识别，Whisper 缺失不阻塞核心功能；
- 后续只有获得完整本地权重并真实验证后才允许显示“已就绪”。

## 不作为 v13 核心依赖

### Chinese-CLIP：暂不随核心版安装

- 原计划用途：直接计算中文文案与画面的相似度；
- 当前没有权重、没有运行库、没有正式入口；
- 现有 Florence 画面描述、语音、业务分类和可解释关键词匹配已经真实跑通；
- 将来素材规模和匹配需求证明有必要时，再作为可选增强包加入。

### BGE-M3：暂不随核心版安装

- 原计划用途：大量文本的多语言语义向量搜索；
- 当前没有权重和运行库；
- 目前 32 个视频使用字符、关键词和明确用户反馈即可工作；
- 它不是被更强模型自动替代，而是现阶段收益不足以抵消安装体积和复杂度；
- 素材达到数千或数万条后可重新评估为可选索引组件。

## 不能删除的边界

- Qwen 权重先保留，等待用户台式机 GPU 验收；
- 空的 Whisper 文件夹、隔离验证缓存和其他无效模型，只列入最终清理候选；
- 未经最终确认，不自动删除任何模型目录。
