# 升级任务 20：单实例与 API 生命周期

## 修复

- 桌面和 API 分别持有 `runtime_data\locks\desktop.lock`、`api.lock` 的系统文件锁；重复启动会明确拒绝，进程异常退出后锁由系统自动释放。
- API 任务管理器关闭时停止接收新任务、取消尚未启动的排队任务，并把它们真实标记为失败和可重试。
- FastAPI 使用 lifespan 调用线程池 shutdown，不再完全依赖下次启动恢复。
- API 启动脚本先检查端口占用，启动后最多 20 秒回读 `/health`；进程提前退出或健康失败会明确报错。
- PowerShell 提示使用 ASCII，避免 Windows PowerShell 5 把无 BOM UTF-8 中文误读成语法错误。

## 验证

- 第二个实例被拒绝、释放锁后可重启的自动测试通过。
- shutdown 可重复调用，关闭后提交任务被拒绝。
- API 在端口 8876 真实启动并通过两次健康检查，测试进程随后精确停止。
- 桌面/API 启动脚本 `ValidateOnly` 均定位到自身 G 盘运行时。
- 当前自动测试：123 项通过。
