# 性能对比报告（P2.6 升级前后）

- **日期**：2026-08-22
- **对比对象**：升级前（单 Worker CPU ASR）vs 升级后（3 Worker + GPU ASR）
- **硬件**：6核12线程 / 32GB / RTX 3050 6GB

---

## 1. ASR 单素材性能（核心瓶颈）

**测试方法**：相同 5 个真实素材（30s 音频），faster-whisper small

| 素材 | GPU float16 | CPU int8 | 加速 |
|---|---|---|---|
| clip_0 | 0.69s | 2.45s | 3.6× |
| clip_2 | 0.54s | 2.96s | 5.5× |
| clip_3 | 0.26s | 9.51s | 36.6× |
| clip_4 | 0.08s | 0.09s | — |
| **平均** | **0.33 s** | **3.02 s** | **9.2×** |

**GPU 推理峰值**：利用率 52%，显存 1.6 GB / 6 GB，温度 42°C

## 2. 全链路吞吐（估算）

### 升级前（P2 单 Worker，生产实测）
- 全阶段（scene+keyframe+asr+ocr）：~0.65 素材/s（约 2.5 分钟/素材）
- ASR 占全链路耗时 ~50-70%（CPU whisper 是主要瓶颈）
- 22,465 素材总耗时：约 9-10 小时/万素材

### 升级后（P2.6 3 Worker + GPU ASR）
- 3 阶段并行：vision/asr/ocr 各 1 Worker（ASR 不再阻塞其他阶段）
- ASR GPU 加速 9.2×：单素材 ASR 从 ~2.5s → ~0.3s
- 预期全链路吞吐：**1.5-2.5 素材/s**（约 2.5-3.5× 提升）

## 3. 调度系统对比

| 指标 | P2（旧） | P2.5（并行） | P2.6（GPU） |
|---|---|---|---|
| Worker 数 | 1 | 3 | 3 |
| ASR 设备 | CPU | CPU | **GPU (auto)** |
| 任务领取 | 无（直接扫库） | 原子领取（BEGIN IMMEDIATE） | 同左 |
| 防重复 | 无 | 幂等护栏 | 同左 |
| 断点恢复 | 无 | recover_stale | 同左 |
| 任务表 | — | analysis_tasks | 同左 |
| 3万任务生成 | — | 0.68s（批量） | 同左 |

## 4. 实测验证

| 验证项 | 结果 |
|---|---|
| 3 Worker 并行 9 任务 | 全 completed，0 失败，无双领 |
| GPU ASR 实际推理 | ✅（8.66s / 0.88s） |
| 幂等跳过已 DONE | ✅（asr 已完任务正确跳过） |
| 数据一致性 | ✅ 只增不减，integrity=ok |

## 5. 结论

> **ASR 单点加速 9.2×，全链路预期 2.5-3.5×，且多 Worker 并行消除了阶段间阻塞。**
> 剩余约 10,000 素材预计从 ~4.5 小时缩短到 ~1.5-2 小时。

## 6. 进一步优化方向（未来）

1. **GPU 化 OCR/视觉**：RapidOCR/Florence 可走 onnxruntime GPU（当前 CPU）
2. **模型升级**：RTX 3050 可跑 whisper medium（显存 2.5GB），中文口播更准
3. **批处理**：ASR 多音频 batch 推理（faster-whisper 支持）
