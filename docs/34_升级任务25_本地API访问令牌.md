# 升级任务 25：本地 API 访问令牌

只绑定 `127.0.0.1` 不能阻止同一电脑上的其他程序调用 TreeCut。现在首次启动 API 会使用密码学安全随机数生成至少 32 字符令牌，原子保存到：

`runtime_data\config\api_token.txt`

除 `/health` 外，所有目录、制作、任务、反馈和素材修改接口必须携带请求头：

`X-TreeCut-Token: <令牌内容>`

缺失或错误返回 HTTP 401。比较使用恒定时间 `secrets.compare_digest`。令牌和临时文件全部位于 G 盘；启动脚本会输出令牌文件位置，但不会把令牌本身打印进日志。

测试验证健康接口无需令牌、目录接口无令牌被拒绝、正确令牌可访问、令牌文件在 G 盘。当前 131 项测试通过。
