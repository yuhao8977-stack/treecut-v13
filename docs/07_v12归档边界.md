# v12 归档边界

## 原则

v12 和历史文件只作为需求、算法和兼容性参考，不再作为正式启动入口，不把旧分析器、旧调度器和宣传性质模块重新接回 v13。

## v13 已迁移的有效能力

- 素材扫描和媒体元数据读取
- 视觉、语音和物体分析思想
- 卖点匹配与镜头规划
- 剪映草稿输出需求
- 本地界面和 API 需求
- 模型池与硬件降级需求（已改为可验证策略）

## 明确不迁移的内容

- 重复调度器和没有正式入口的旧分析器
- 没有权重、依赖或真实调用证据的模型占位
- 抽取 0 帧、空结果仍算成功的测试
- 没有证据的“自动学习、自我进化”宣传接口
- 与某台电脑固定盘符、用户目录或 C 盘环境绑定的路径

## 删除策略

当前不自动删除 v12、桌面原始视频或 v13 测试副本。只有在用户查看干净便携版并明确同意后，才按 `03_测试素材清理清单.md` 精确清理测试副本和测试输出。任何正式素材和用户项目都不进入自动清理范围。
