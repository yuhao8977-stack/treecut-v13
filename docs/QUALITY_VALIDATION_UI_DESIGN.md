# 质量验证 UI 设计（P2.7）

- **日期**：2026-08-24
- **技术栈**：tkinter（与既有桌面 UI 一致），三栏布局 1560×900
- **入口**：`python -m treecut.main --quality-review`

---

## 1. 页面结构

```
┌─────────────────────────────────────────────────────────────────────┐
│ 工具栏: [操作员] [◀ 上一个] [下一个 ▶] [进度 3/100] [刷新] [保存全部] │
├──────────────┬─────────────────────────────────┬────────────────────┤
│ 左：素材+视频  │ 中：AI 分析结果                 │ 右：人工评价       │
│              │                                 │                    │
│ 素材信息      │ ① 场景识别 (Scene)              │ AI 结果逐项评价    │
│ (ID/分类/路径)│   算法/段数/场景段               │ 场景: ✅⚠️❌ [修改] │
│              │ ② 关键帧 (Keyframe)              │ 转写: ✅⚠️❌ [修改] │
│ 视频预览      │   帧数/清晰度/亮度               │ OCR:  ✅⚠️❌ [修改] │
│ [播放][截帧]  │ ③ 语音识别 (ASR)                │ 关键帧:✅⚠️❌ [修改] │
│              │   完整转写文本                   │ 标签:  ✅⚠️❌ [修改] │
│ 关键帧缩略图  │ ④ 文字识别 (OCR)                │                    │
│ (最多6张)     │   识别文本列表                   │ 素材评分 (100分)    │
│              │ ⑤ 标签 (Labels)                 │ 场景/产品/功能/     │
│              │   标签+来源                      │ 价值/商业 各0/10/20 │
│              │                                 │ 总分显示            │
│              │                                 │ 素材状态:           │
│              │                                 │ READY/REVIEW/...    │
│              │                                 │ 备注                │
└──────────────┴─────────────────────────────────┴────────────────────┘
```

## 2. 三栏功能明细

### 左栏：视频播放器 + 关键帧
| 组件 | 功能 |
|---|---|
| 素材信息 | 显示 asset_id、分类、相对路径 |
| 视频预览 | cv2 截取首帧 + `os.startfile` 系统播放器（含声音） |
| 关键帧缩略图 | 最多 6 张关键帧图片（PIL 缩略图） |

### 中栏：AI 分析结果（只读）
| 区块 | 数据源 | 展示 |
|---|---|---|
| ① 场景识别 | `asset_processing_state(scene)` + `segments` | 算法版本、状态、场景段数、各段时间戳 |
| ② 关键帧 | `keyframes` | 帧数、各帧时间戳/清晰度/亮度 |
| ③ ASR | `transcripts` | 完整语音转写文本 |
| ④ OCR | `ocr_text` | 识别文本列表（带时间戳） |
| ⑤ 标签 | `labels` | 标签 + 来源（model/human） |

### 右栏：人工评价
| 区块 | 组件 |
|---|---|
| AI 结果逐项评价 | 每项 ✅正确/⚠️部分/❌错误 单选 + 人工修正输入框 |
| 素材评分 | 5 维 × (0/10/20) 单选 + 总分实时计算 + 等级提示 |
| 素材状态 | READY/REVIEW/HIGH_VALUE/LOW_VALUE/REJECTED/BROKEN 单选 |
| 备注 | 多行文本 |

## 3. 交互流程

```
1. 启动 --quality-review → 加载 sample_100.json 抽检队列
2. 查看当前素材：左视频/关键帧 + 中 AI 结果
3. 逐项评价 AI 结果（✅/⚠️/❌）+ 可修改
4. 五维评分（0/10/20）+ 状态选择 + 备注
5. 点"保存全部" → 写入 human_feedback/asset_quality/asset_status
6. 自动进入下一个素材
```

## 4. 数据写入（新增表）

| 保存项 | 表 | 字段 |
|---|---|---|
| 逐项评价 | human_feedback | asset_id/ai_type/ai_label/human_label/verdict/comment/operator |
| 评分 | asset_quality | 5 维分数 + total + reviewer |
| 状态 | asset_status | status/source=human |

## 5. 抽检队列（sample_100.json）

由 `Sampler.build_sample()` 生成，100 素材覆盖：
- 客户案例 30 / 工厂 20 / 产品细节 20 / 安装 10 / 其他 20
- 从未审核素材随机抽取（排除已评分/BROKEN）
