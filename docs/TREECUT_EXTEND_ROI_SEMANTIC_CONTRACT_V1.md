# TreeCut EXTEND ROI 语义契约 V1（POST-A3 calibration 用）

- 状态：草案（供 calibration 第二轮人工 ROI 前评审/修订）
- 背景：A3 blind 暴露 GEOM01（bbox 面积≠方向）与 ID01（目标收回态不可见）。ROI 语义不一致会直接污染
  RELATIVE_ANCHOR_V1 的锚点特征，因此先定框什么、再画框。

## 1. 三个核心对象（EXTEND 目标系）
| 对象 | 框什么 | 判定要点 |
|---|---|---|
| `TABLETOP`（桌板/台面） | 岛台上**不可伸缩的主台面/固定桌面部分**（不动的部分） | 若整张台面整体参与伸缩（无独立固定部），此标可空缺，用 EXTENSION_TABLETOP 覆盖动件 |
| `EXTENSION_TABLETOP`（伸缩桌板） | **真正可伸缩的子板/拉出部件本身**（动件） | 收回态被遮挡/半隐藏时：可见部分照框；完全不可见则该帧**不框**（标注系统记 TARGET_NOT_VISIBLE），禁止用岛台或猜测框代替 |
| `ISLAND_BODY`（岛台主体） | 固定柜体/台座主体（**稳定参照**，供归一化） | 全窗口尽量一致地框同一主体；若取景变化导致主体不同，逐帧如实框当前主体（RELATIVE_ANCHOR 用其归一化，需稳定） |

## 2. 边界规则
- `EXTENSION_TABLETOP` 与 `TABLETOP` 视觉重叠时：能区分就分开框；无法区分（同一块板既当主面又当动件）时，
  统一只框 `EXTENSION_TABLETOP`（动件优先），并在备注写明"单件整体伸缩，未单框固定桌板"。
- 人/手遮挡动件时：可见部分照框；同时把遮挡的人/手另框（`PERSON`/`HAND`），便于干扰归因。
- 桌腿/柜门/水槽/抽屉/插座等：属**非目标前景**（若与目标重叠或参与干扰运动再框对应标签），
  不得用其运动推断桌板动作，也不得作为 EXTEND 目标。

## 3. 为何这样定义（A3 教训）
- A3 H001（NEG）中 EXTENSION_TABLETOP 仅 3/5 帧可见 → 语义判定帧应允许部分不可见（VISIBLE_3/5），
  但**不许自动补框**。
- A3 几何原始结果：2/3 正例判 RETRACT、2/3 负例判 EXTEND → 若人工框同时覆盖"静止主面+动件"混叠，
  面积/锚点都会失真。本契约强制动件/固定件分离，供 RELATIVE_ANCHOR_V1 使用干净锚边。
- 统一 5 帧采样不变；此处只约束"框的语义"，不新增帧。

## 4. 示例
- 伸缩餐桌岛台（60cm）：`ISLAND_BODY`=柜体+固定腿；`EXTENSION_TABLETOP`=可滑出那块桌面板（含拉出过程整体）；
  `TABLETOP`=若另有固定台面则框，否则留空。
- 岩板一字腿（腿伸缩型）：主体不是桌板伸缩 → EXTENSION_TABLETOP/TABLETOP 按画面实情可空；桌腿运动属干扰，
  用 `ROCK_TABLE_LEG`（如有该标签需求）并归 NO_ACTION，除非桌面确实随腿联动位移。

## 5. 校验收口
- 第二轮人工 ROI 页将依本契约标注（对 26 候选中入选的 12+ 案例）；每帧 ≥1 目标或明确 TARGET_NOT_VISIBLE。
