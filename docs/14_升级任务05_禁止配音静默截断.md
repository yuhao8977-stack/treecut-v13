# 升级任务 05：禁止配音和字幕静默截断

## 要解决的问题

旧逻辑先生成完整 TTS，然后用画面时长 `-t` 封装。配音比画面长时，后半段语音和字幕会被直接裁掉，但任务仍可能成功。

## 完成内容

- TTS 生成后立即读取真实 WAV 时长。
- 配音长于画面时，在 FFmpeg 封装前明确失败。
- 错误信息显示配音秒数、画面秒数和解决建议。
- 配音与画面恰好等长允许通过。
- 0 秒或无效时长明确拒绝。
- 剪映草稿不再对配音使用 `min(total, voice.duration)` 静默裁切。
- 剪映配音超过项目末尾时明确失败。
- 每条字幕超过项目末尾时明确失败。
- 恰好结束在项目末尾的配音/字幕允许通过。

## 验收结果

- 新增 5 项时间边界测试。
- 全量自动测试由 76 项增加到 81 项，81/81 通过。
- 真实离线 TTS 生成一段 15.372 秒中文配音。
- 测试画面真实时长 2.00 秒。
- 软件返回明确错误：“配音长于画面，禁止静默截断”。
- 目标 MP4 文件不存在，证明在封装前停止，没有留下被截断的假成片。
- 所有验证文件均位于 G 盘隔离目录。

## 当前用户处理方式

出现该提示时，可以增加目标时长或缩短配音文案。后续会增加“先估算配音并自动建议时长/在安全范围内调速”的用户辅助，但无论增加何种自动方案，都必须保留本次建立的禁止静默截断底线。
