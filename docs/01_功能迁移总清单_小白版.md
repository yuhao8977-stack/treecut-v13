# TreeCut v12 → v13 功能迁移总清单

## 已验证并迁移时保留

| 功能 | v12 真实状态 | v13 处理 |
|---|---|---|
| 剪映草稿生成 | 已真实生成并验证草稿结构 | 重写为统一输出适配器 |
| 视频抽帧 | 可真实抽取视频帧 | 保留能力，统一使用内置 FFmpeg |
| Florence 画面分析 | CPU 可真实推理 | 作为无 CUDA 电脑的默认视觉模型 |
| Qwen3-VL | 权重完整，当前电脑无 CUDA | 作为 NVIDIA CUDA 高性能视觉模型 |
| SenseVoice | CPU 可真实识别中文 | 作为离线语音识别和情绪识别模型 |
| YOLOv8n | CPU 可真实推理 | 只负责通用物体和人物检测 |
| Edge TTS | 可生成配音，但依赖网络 | 降为联网备用方案 |
| 本地素材索引 | 字符索引可工作 | 小素材库备用，大素材库迁移到语义向量索引 |
| API | 基础任务接口可运行 | 统一使用与桌面程序相同的工作流 |

## 存在但未真正接入正式流程

| 模块 | 发现的问题 | 决定 |
|---|---|---|
| UnifiedAudioAnalyzer | 只有定义，正式分析器没有调用 | 提取有效逻辑后并入统一语音服务 |
| 旧 ClipMatcher | 只有定义，没有正式消费者 | 不原样迁移，改成统一图文匹配适配器 |
| SelfLearningEngine | 基本没有正式调用入口 | 架构完成后做真假闭环验证 |
| ModelPool | 没有成为统一模型入口 | v13 重建真正的模型注册中心 |
| DriveScanner | 没有接入用户主流程 | 重写为素材来源发现服务 |
| SmartVideoAnalyzer | 与 VideoAnalyzer 职责重叠 | 合并为一个分析工作流 |
| Orchestrator/SmartOrchestrator | 两套调度逻辑重叠 | 合并为一个工作流调度器 |

## 明确需要新增或补齐

- 离线中文 TTS；
- 本地 Whisper 及逐句时间戳；
- CLIP 图文画面匹配；
- BGE-M3 中文语义检索；
- 磁盘、移动硬盘和共享盘素材自动发现；
- 剪映草稿与 MP4 双输出；
- Windows 单一桌面入口；
- 四层测试：单元、模块集成、完整工作流、真实用户验收；
- 跨硬件测试：无显卡、NVIDIA 显卡、断网、移动硬盘和共享盘。
