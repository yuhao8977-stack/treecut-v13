# AI 认知体系 Phase 1 报告 — 行业知识引擎

- **日期**：2026-08-24
- **范围**：Layer 3（行业知识）+ Layer 4（内容分类）规则引擎 V1
- **数据源**：100 素材抽检队列（sample_100.json）

---

## 1. 实施内容

### 1.1 行业特征抽取引擎（`cognitive/industry.py`）

从 **ASR 文本 + OCR 文本 + 素材路径** 提取 4 类行业特征：

| 特征 | 识别内容 | 匹配方式 |
|---|---|---|
| 产品识别 | 岛台/伸缩岛台/岩板岛台/实木岛台/餐边柜/橱柜 | 知识库 keywords + 权重 |
| 材料识别 | 岩板/潘多拉/寒江雪/黑胡桃/木纹/肤感/烤漆 | 知识库 keywords + 权重 |
| 功能识别 | 伸缩/收纳/隐藏/插座/隐藏电器/水吧 | 独立 FUNCTION_KEYWORDS 表 |
| 场景识别 | 客户家/工厂/展厅/厨房/安装现场 | 知识库 keywords + 权重 |

**评分算法**：`score = min(1.0, 0.4 + 0.15 × 命中关键词数) × 知识权重`，按分数排序取 Top。

### 1.2 内容分类引擎

5 类内容类型（客户案例/产品介绍/工厂实力/装修方案/避坑知识），各带关键词表 + 权重，置信度 `min(0.95, 0.4 + 0.12 × 命中数) × 权重`。

### 1.3 数据落库（cognitive 新表）

- `content_classification`：每素材一条（内容类型 + 置信度 + reasons JSON）
- `scene_semantics`：场景/产品语义标签

## 4. 局限与原因分析

| 局限 | 原因 | 对策 |
|---|---|---|
| 36% 素材无产品识别 | ASR 文本过短（平均 37 字符，纯展示无解说） | Phase 2 接入视觉模型（Qwen-VL）识别画面 |
| 装修方案/避坑知识为 0 | 素材库内容以案例/产品为主，无此类内容 | 正常，非引擎缺陷 |
| 置信度偏低（0.52-0.64） | 保守评分（避免过度自信） | 可调阈值 |

**覆盖数据基础**：全库 22,465 资产中，有 ASR 16,168（72%）、有 OCR 11,971（53%）——约 28% 素材无 ASR 文本，需要视觉补充。
