# 升级任务 14：Whisper、中文 CLIP、BGE-M3 真实接入

## 小白结论

以前这三项是“设计里提到了，但模型不完整或不存在”。现在三套本地模型都已放入 G 盘，经过文件检查和真实计算，并接入正式链路。

- Whisper：听视频中的人声，生成文字、分段时间和逐词时间，帮助字幕与画面对齐。
- 中文 CLIP：直接比较“中文画面需求”和“视频代表画面”，帮助判断画面是否切题。
- BGE-M3：理解中文句子的语义，帮助识别文字不同但意思相近的卖点、字幕和画面描述。

## 实际验证结果

- Whisper-small：识别中文测试音频，得到 1 个语音段、12 个逐词时间点。
- 中文 CLIP：在真实烤箱视频帧上，把“打开的嵌入式烤箱”排在无关画面描述之前。
- BGE-M3：成功生成 1024 维有限数值向量，同义产品描述得分高于无关描述。
- Florence-2 和 YOLO：升级 PyTorch 后重新加载和推理成功。
- 自动测试：新增语义模型不得凭空制造素材匹配的保护测试。

## 安全与运行策略

模型全部使用本地文件并禁止联网下载。旧 PyTorch 无法安全读取 `.bin` 权重，因此便携运行环境升级到 PyTorch 2.6 CPU 版，安装包 SHA-256 已与官方索引核对。

语义模型只在原有可解释证据（字幕、画面描述、对象、文件名或分类）命中后做加减分，避免分数接近时误选无关素材。生产报告会记录 BGE/CLIP 是否参与、各自分数和错误，不允许静默假运行。

## 磁盘约束

模型、下载包、缓存、验证凭证、测试输出都位于 `G:\TreeCut_v13`。YOLO 独立回归测试曾生成一个 C 盘配置文件，已删除；正式启动会把 `YOLO_CONFIG_DIR` 指向 G 盘缓存目录。
