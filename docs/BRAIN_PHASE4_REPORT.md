# AI 认知体系 Phase 4 报告 — 反馈学习闭环

- **日期**：2026-08-24
- **范围**：Layer 7 反馈学习引擎（差异归类 → 规则提炼 → 权重更新 → 效果评估）
- **状态**：机制已验证可工作；真实反馈待人工积累（认知 UI 已提供入口）

---

## 1. 实施内容

### 1.1 反馈学习引擎（`cognitive/learning.py`）

**闭环**：
```
人工修正（认知 UI → learning_rules / P2.7 → human_feedback）
  → 按 error_type 归类（content_type_mismatch / business_adjust）
  → 提炼修正规则（从素材 ASR/OCR 提取关键词，形成"关键词→正确类型"建议）
  → 更新知识库权重（多次人工确认的类型自动加权）
  → 重跑分类评估准确率
```

**反馈源**：
| 来源 | 数据 | 说明 |
|---|---|---|
| learning_rules | 认知 UI 保存的 AI vs 人工差异 | error_type=content_type_mismatch |
| human_feedback | P2.7 质量审核 | verdict=wrong/partial + ai_type=scene/label |

### 1.2 学习动作

1. **规则提炼**：对每条差异，检查素材 ASR/OCR 文本，若发现显著行业词（岛台/岩板等）→ 生成"关键词建议：素材含 X，类型 A → 应判 B"
2. **权重更新**：同一内容类型被人工修正 ≥2 次 → `knowledge_entries.weight` 提升 0.1×min(次数,5)，上限 3.0
3. **效果评估**：反馈前后同批素材 AI 分类与人工一致率对比

### 1.3 CLI

- `--brain-learn`：执行一次学习
- `--brain-learn-status`：待学习反馈量

## 2. 机制验证（模拟反馈）

插入 6 条模拟差异（AI 判工厂/产品 → 人工改客户案例）后执行学习：

| 指标 | 结果 |
|---|---|
| 处理反馈 | 12 条 |
| 差异数 | 12 |
| **规则提炼** | **10 条**（如"素材含[岛台,厨房]，工厂实力→客户案例"） |
| **权重更新** | **2 次** |

**权重变化**：
| 内容类型 | 学习前 | 学习后 |
|---|---|---|
| 客户案例 | 1.0 | **1.5**（+0.5，多次人工确认） |
| 产品介绍 | 1.0 | **1.2**（+0.2） |
| 工厂实力 | 0.9 | 0.9 |
| 装修方案 | 0.8 | 0.8 |
| 避坑知识 | 0.8 | 0.8 |

**结论**：学习闭环可工作——差异被正确归类、规则被提炼、权重按人工确认频率更新。

## 3. 真实反馈积累路径

当前 `learning_rules=0`（人工尚未开始用认知 UI 审核）。积累路径：

1. **认知 UI**（`--brain-ui`，运行中）：运营人员逐素材确认 → 差异自动进 learning_rules
2. **P2.7 质量审核 UI**（`--quality-review`，运行中）：verdict=❌/⚠️ 的记录进 human_feedback
3. 每积累一批（如 50-100 条），执行 `--brain-learn` 触发学习

**预期效果**（设计目标）：连续 500 条反馈后，内容分类准确率提升 ≥10%。

## 4. 局限与说明

| 项 | 说明 |
|---|---|
| 规则提炼为关键词级 | V1 规则引擎的能力边界；V2 可结合 LLM 做语义级学习 |
| 权重更新较保守 | 防过拟合；同一类型需多次确认才显著加权 |
| 准确率评估为简化版 | 直接比较 AI vs 人工；后续可接入完整重算流水线 |
| 真实反馈未积累 | 引擎就绪，等待人工使用 UI 产生数据 |
