# 升级任务 24：素材库管理、失败详情、人工分类与单条重跑

## 桌面新增“素材库管理”

- 素材来源在线/离线状态。
- 每个来源当前可用文件数和分析失败数。
- 每条素材的编号、分析状态、业务分类、尝试次数、失败原因、绝对路径。
- 刷新时按硬盘卷标尝试重新关联盘符。
- 人工分类修正，来源明确记录为 `user_override`。
- 指定某一视频重新分析；工作器只领取该素材，不会误跑另一个排队任务。

## API 新增

- `GET /catalog/media`
- `POST /catalog/media/{media_id}/retry`
- `PATCH /catalog/media/{media_id}/category`

状态、分类、数量和离线错误均有输入验证与明确 HTTP 错误。后端测试覆盖失败详情、来源统计、分类修改、重排队和指定领取。主版本 130 项测试通过。
