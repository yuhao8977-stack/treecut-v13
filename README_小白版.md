# TreeCut v13（树剪新架构）

这是从 TreeCut v12 隔离迁移出来的新版本。v12 继续保留，直到 v13 完成全部验收。

## 最终目标

把大量视频放入素材库后，树剪自动完成：

1. 发现本机硬盘、移动硬盘和共享盘中的素材；
2. 分析画面、人物、产品、语音和场景；
3. 根据产品卖点或文案挑选合适画面；
4. 生成配音、字幕、音乐和剪辑时间线；
5. 根据用户选择生成剪映草稿或直接输出 MP4。

## 重要原则

- 普通用户只使用一个 Windows 启动入口。
- 同一个安装包适配台式机、游戏本和办公本。
- 有 NVIDIA 显卡时使用高性能模型；没有时自动选择 CPU 模型。
- 所有模型、缓存、数据库和临时文件默认放在软件所在硬盘，不占用 C 盘。
- 每项功能必须真实接入正式流程并通过测试，不能只建立空模块。
- v12 文件在迁移完成前不会删除。

## 现在怎么启动

- 普通使用：双击 `启动树剪v13.cmd`。
- 本地接口：双击 `启动树剪本地接口.cmd`。
- 软件运行期间不要拔出安装盘；如需拔盘，先退出树剪并安全弹出硬盘。
- 素材盘暂时离线不会删除素材记录；重新接入后软件会尝试自动重连。
- 测试素材原件仍保留在桌面；G 盘测试副本会在全部验收结束并再次确认后删除。
